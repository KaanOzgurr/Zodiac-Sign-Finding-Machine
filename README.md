Horoscope Calculator

A simple console-based Java program that determines a user's horoscope sign based on their birth month and day.

Features

Prompts the user to enter their birth month and day

Validates the input for correct date ranges

Calculates and displays the horoscope sign according to Western astrology

Provides error messages for invalid input

How to Run

Clone the repository:

git clone https://github.com/yourusername/your-repo-name.git


Open the project in your favorite Java IDE (e.g., IntelliJ IDEA, Eclipse).

Compile and run the Main class.

Follow the on-screen instructions to enter your birth month and day.

The program will display your horoscope sign or notify you if the input is invalid.

Example
Your birth month:
3
Your birth day:
15
Your horoscope is: Pisces

Requirements

Java Development Kit (JDK) 8 or higher
